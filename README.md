# Avtonom

Пример демонстрирует использование Google Gemini API для запуска
интерактивного агента, который работает в каталоге `workspace`.
Агент умеет читать и изменять файлы, выполнять команды терминала и
создавать планы из нескольких шагов. Скрипт `gemini_agent.py` запускает
чат с моделью `gemini-2.0-flash` и поддерживает функцию построения плана
(`create_plan`) с последующим его выполнением (`execute_plan`).

Перед запуском убедитесь, что в файле `.env` указан рабочий API‑ключ.
Зависимости устанавливаются в папку `env` командой:

```bash
pip install --target ./env google-generativeai python-dotenv
```

Запуск агента:

```bash
python3 gemini_agent.py
```
